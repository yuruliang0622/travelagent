06 Tech Stack + Memory

Built on Gemini, Google Maps, and MongoDB Atlas.

Reiko

Tech stack used

AgentGemini + Agent Builder — plans routes and orchestrates tool calls.
MemoryReiko remembers your past trips and taste — MongoDB MCP + Atlas Vector Search.
GroundingGoogle Maps Platform — real places, coordinates, ratings, hours.
FrontendReact — chat, live map, day-by-day timeline, and tool trace.
BackendFastAPI on Cloud Run serving the agent workflow as a web app.

Memory + MCP flow

01 · Store Atlas remembers you Profile, preferences & past trips persist in MongoDB Atlas.
02 · Expose MCP server The MongoDB MCP server surfaces that memory as agent tools.
03 · Recall Agent grounds the plan Gemini queries MCP to tailor the trip to who you are.
04 · Save Write back The finished itinerary returns to Atlas, enriching memory.
